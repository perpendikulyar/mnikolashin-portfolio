# 🤝 Contributing

Спасибо за интерес к проекту портфолио Михаила Николашина.

## 📌 Важно: Приватный проект

Этот проект является **приватным** и не подразумевает открытое сообщество контрибьюторов.

**Правила участия:**
- ✅ Проект не для свободного вклада (open-source)
- ✅ Изменения вносятся **только по выданному доступу** к исходным кодам
- ✅ Если вы не получали явного приглашения на участие — пожалуйста, не создавайте pull requests
- ✅ Все изменения должны соответствовать целям проекта (Senior Product Manager Portfolio)

## 📞 Как внести изменения

### Для авторизованных участников:

1. **Создайте ветку** от `main`:
   ```bash
   git checkout -b feature/<название-фичи>  # или fix/<баг>, design/<изменение>
   ```

2. **Внесите изменения** и протестируйте их локально:
   ```bash
   npm run dev      # Запуск dev-сервера
   npm run lint     # Проверка кода
   npm run format   # Форматирование
   npm test         # Запуск тестов
   ```

3. **Создайте Pull Request**:
   ```bash
   gh pr create --title "Описание изменений" --body "Детальное описание"
   ```

4. **Обновите документацию** (если применимо):
   - Обновите `README.md` для новых фич
   - Обновите `BACKLOG.md` для отслеживания задач
   - Добавьте комментарии в код при необходимости

## 🐛 Баги и проблемы

Если вы нашли баг, **только авторизованные участники** могут создавать issues.

Для сообщений о багах используйте:
- GitHub Issues (для авторизованных участников)
- Email: perpendikulyar@gmail.com

## 🎨 Дизайн-изменения

Для изменений дизайна:
1. Создайте макет в Figma (если есть доступ)
2. Добавьте ссылку на макет в PR
3. Укажите изменения в `BACKLOG.md`

- **JavaScript/JSX:** ESLint + Prettier (конфиги в `.eslintrc.json` и `.prettierrc`)
- **CSS:** TailwindCSS utility-first подход
- **Коммиты:** Conventional Commits (`feat:`, `fix:`, `design:`, `refactor:`, `docs:`, `chore:`)
